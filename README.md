# رها — اپ ترک سیگار

نسخه‌ی اولیه‌ی اپ فارسی ترک سیگار برای اندروید.

## نصب روی گوشی
هر بار که کدی به این مخزن اضافه شود، گیت‌هاب خودش فایل نصبی (APK) را می‌سازد.
فایل آماده را از بخش **Releases** (ستون سمت راست صفحه‌ی اصلی مخزن) دانلود و روی گوشی نصب کنید.

## ساختار
- `www/` — خودِ اپ (صفحه‌ها، ظاهر و منطق)
- `.github/workflows/build-apk.yml` — دستورالعمل ساخت خودکار APK
- `capacitor.config.json` — تنظیمات تبدیل اپ وب به اپ اندروید
