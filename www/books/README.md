# پوشه‌ی کتاب‌ها

هر کتاب را در یک پوشه‌ی جداگانه همین‌جا بگذارید. اسم پوشه، اسم کتاب می‌شود.

- کتاب PDF یا EPUB: فایل `.pdf` یا `.epub` را داخل پوشه بگذارید.
- کتاب صوتی: همه‌ی فایل‌های صوتی (`.mp3` و …) را داخل پوشه بگذارید. ترتیب فصل‌ها از روی شماره‌ی اول اسم فایل است، مثلاً `01-مقدمه.mp3`، `02-فصل اول.mp3`.
- یک کتاب می‌تواند هم نسخه‌ی متنی و هم صوتی داشته باشد؛ هر دو را در یک پوشه بگذارید.
- جلد (اختیاری): عکسی با نام `cover.jpg` یا `cover.png`.
- توضیحات (اختیاری): فایلی با نام `info.json` مثل این:

```json
{ "title": "اسم کامل کتاب", "author": "نویسنده", "description": "توضیح کوتاه", "order": 1 }
```

هر فایل باید کمتر از ۱۰۰ مگابایت باشد (محدودیت گیت‌هاب).
